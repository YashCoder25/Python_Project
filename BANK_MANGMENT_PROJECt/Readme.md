1. Bank Management System
A banking application built with Python and Streamlit. It also includes a command-line version.

Features
- Create a bank account
- Deposit money
- Withdraw money
- View account details
- Update account information
- Delete an account
- Store account records in a JSON file
- Use either a command-line interface or a Streamlit web interface
Technologies
- Python
- Streamlit
- JSON
- Object-Oriented Programming (OOP)
Project folder: Bank-Management-System/

Run the Streamlit application
cd Bank-Management-System
pip install -r requirements.txt
streamlit run app.py
Run the command-line application
cd Bank-Management-System
python main.py
See [`Bank-Management-System/README.md`](Bank-Management-System/README.md) for complete setup instructions and details.
